Features

Everything in one place. Nothing in your way.

Choose the problem and the studio handles the rest-agents that use your files, run your projects and stay on schedule.

Multi-agent workspace

Built-in agents-Goodstuff, Pi and OpenCode-plus your own. Each gets its own model, tools and personality.

Projects & sessions

Keep chats organised per project, with full history, project files and context that carries over.

Agent compare

Run the same task across several agents side by side, then keep the best answer.

Skills system

Point the studio at a skills folder and every agent picks up new abilities instantly.

Scheduled tasks

Cron-style recurring agent jobs with their own skills-work that happens while you're away.

Built-in browser

A real browser panel with a URL bar, back and forward-right next to your chat.

Live site preview

Serve and preview project sites instantly in Page or App mode, with live refresh.

Universal dev server

npm, yarn, pnpm, bun or PHP-the studio detects your project, installs dependencies and runs it.

Files panel

Browse the workspace and open PDF, Word, Excel and Markdown files right inside the app.

Any model

Hosted models or fully local-your Ollama models are detected automatically. Switch per chat.

Long-chat compaction

Long sessions stay sharp: context is compacted automatically, with a live token meter.

Make it yours

Accent presets, custom themes, fonts and border styles-with a live preview before you save.

Real screens from the app-click any of them to look closer.
