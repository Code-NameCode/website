# Goodstuff Designs - Design Styles

An internal style library of 82 working examples: 80 named visual styles plus two layout archetypes (an application shell and a single-product page). Each is a self-contained page built to be opened and read, not a screenshot.

Browse them as live pages at [design-styles](/design-styles). The gallery loads ten at a time and can be expanded.

## How styles combine

A combination only earns its place when it serves the content or the brand. Name one dominant style and no more than two supporting ones. The primary style sets structure, grid, spacing and type rhythm; a secondary style shapes content presentation and tone; an accent style is confined to small details such as buttons, labels, dividers, or one signature section. Supporting styles must not override the primary style's core logic.

Tokens must not conflict when styles are mixed: at most two font families, one base palette with one accent system, one radius logic, one depth model, and one motion and easing language.

Approved pairings: Swiss + Editorial, Luxury + Minimalist, Cyberpunk + Terminal, Industrial + Brutalist, SaaS + Bento, Editorial + Ecommerce, Organic + Luxury, Minimalist + Typography First, Developer Focused + Dashboard, Cinematic + Storytelling, Retro Futurism + Science Fiction Interface, Neo Brutalism + Playful.
