# Goodstuff-Studio - AI workspace for Windows

Goodstuff-Studio is a desktop AI workspace for Windows by Goodstuff Designs: agents, projects, notes, skills, scheduled tasks and a built-in browser in one fast app. Free download at https://studio.goodstuffdesigns.co.za/

## Features

- **Multi-agent workspace** - built-in agents (Goodstuff, Pi and OpenCode) plus your own, each with its own model, tools and personality. Compare answers side by side.
- **Projects and sessions** - chats organised per project, with full history, project files and context that carries over.
- **Agent compare** - run the same task across several agents side by side, then keep the best answer.
- **Skills system** - point the studio at a skills folder and every agent picks up new abilities instantly.
- **Scheduled tasks** - cron-style recurring agent jobs with their own skills, running while you are away.
- **Built-in browser** - a real browser panel with URL bar and navigation next to your chat.
- **Live site preview** - serve and preview project sites instantly in Page or App mode with live refresh.
- **Universal dev server** - npm, yarn, pnpm, bun or PHP: the studio detects the project, installs dependencies and runs it.
- **Files panel** - browse the workspace and open PDF, Word, Excel and Markdown files inside the app.
- **Any model** - hosted models or fully local; Ollama models are detected automatically. Switch per chat.
- **Long-chat compaction** - context is compacted automatically, with a live token meter.
- **Customisation** - accent presets, custom themes, fonts and border styles with live preview.

## Platform

Windows 10 and 11. Local-first: your files stay on your machine. Works with hosted models or your own Ollama install.
