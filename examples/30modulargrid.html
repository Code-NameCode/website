M01Foundations — type scale

Six sizes, no exceptions in the wild.

The scale is derived from an 8px base unit and a 1.25 ratio, rounded to whole pixels at every step. A seventh size was proposed in 2024 and retired after it appeared in production four times.

Radius & elevation

0 — module, table, panel
4 — input, button, chip
8 — popover, menu
full — avatar, toggle, progress

Elevation is a 1px rule, not a shadow. Shadows are reserved for floating layers only.

Breakpoints & columns

4 columns < 640
8 columns < 1024
12 columns ≥ 1024
24px column gap, always
1280px max content

Components declare spans in columns, never pixels, so the same markup works at every size.

M04Token reference

The eleven tokens a product team actually touches.

M05Release cadence

Every second Thursday, whether it is finished or not.

Six releases a year, dated, with a migration note for anything breaking. A release never ships a component without the same change on iOS and Android — that is the whole point of the schedule.

v4.3 · 13 Nov

Overlay family

Dialog, drawer and popover graduate from beta with focus-trap and scroll-lock parity across platforms.

Focus ring

M06Get the package

Install Ostara in an afternoon.

One package per platform, a token file you commit, and a lint rule that keeps raw values out. The migration guide assumes you are starting from nothing.

npm i @ostara/react · swift package Ostara · gradle dev.ostara:compose

Decides which migration guide we send first.
