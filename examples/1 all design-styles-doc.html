Combining styles

Use a combination only when it serves the content or the brand. Name one dominant style and no more than two supporting ones. The primary style controls page structure, grid, spacing, typography rhythm, and component architecture; a secondary style influences content presentation, imagery, and tone; an accent style is confined to small details such as buttons, labels, dividers, or one signature section. Supporting styles must not override the primary style's core logic.

Tokens must not conflict when styles are mixed: at most two font families, one base palette with one accent system, one radius logic, one depth model, and one motion and easing language. The library's approved pairings are:

  • Swiss + Editorial
  • Luxury + Minimalist
  • Cyberpunk + Terminal
  • Industrial + Brutalist
  • SaaS + Bento
  • Editorial + Ecommerce
  • Organic + Luxury
  • Minimalist + Typography First
  • Developer Focused + Dashboard
  • Cinematic + Storytelling
  • Retro Futurism + Science Fiction Interface
  • Neo Brutalism + Playful

The 80 styles

Each entry is a written explanation drawn from the style's own philosophy, use cases, typography, color and layout — followed by the practical specifics: where it belongs, the CSS and component patterns behind it, and the mistakes that give it away.

01

Minimalist

Reduce interface to essential structure; hierarchy comes from typography, whitespace, and alignment. It earns its place on portfolios, premium services, focused landing pages, documentation and calm product sites. Typography is part of the brief: clean sans or refined serif/sans pairing; strong scale contrast; moderate line-height; avoid too many weights. The palette is specific: 1 neutral family plus 1 restrained accent; high text contrast; backgrounds usually white, off-white, or deep neutral. Structure carries the rest: simple grids; generous whitespace; narrow readable containers; deliberate section rhythm. Edges stay quiet: subtle borders; small or no radius; minimal shadows.

Best for
  • portfolios
  • premium services
  • focused landing pages
  • documentation
  • calm product sites
CSS / patterns
CSS variables, max-width containers, clamp typography, border-top sectioning, :focus-visible outlines.
Avoid
Mistakes to avoidEmpty-feeling pages, weak hierarchy, hidden affordances, unnecessary cards, excessive color, decorative gradients.

02

Modern Corporate

Trust, clarity, professionalism, readability, and predictable structure. It is built for B2B, services, finance, healthcare, manufacturing, legal and enterprise SaaS. The type treatment is deliberate — contemporary sans; authoritative headings; comfortable body text; clear section labels. Color is part of the definition rather than an afterthought: brand colors used sparingly; neutral backgrounds; clear semantic colors; avoid loud palettes. Layout decisions stay consistent with that: structured 12-column grids; conventional content sections; balanced density. Interaction is restrained transitions; no gimmicks.

Best for
  • B2B
  • services
  • finance
  • healthcare
  • manufacturing
  • legal
  • enterprise SaaS
CSS / patterns
Tokenized brand palette, grid utilities, accessible dropdowns, container queries.
Avoid
Mistakes to avoidExperimental nav that harms usability, stock-photo cliché, generic SaaS template for non-SaaS company.

03

Editorial

Digital publication; rhythm, storytelling, and typography drive the page. Best suited to articles, magazines, brand stories, reports, campaigns and culture sites. Type carries a lot of the weight here: strong serif/display headlines with readable body; captions, metadata, pull quotes. Color follows the philosophy: often restrained to support imagery; accent colors for issue/section identity. Layout, grid, and spacing follow the same logic: editorial columns, asymmetry, large visual moments, text columns with measured line lengths. Edges stay quiet: borders for rules/dividers; minimal shadows; radius usually low.

Best for
  • articles
  • magazines
  • brand stories
  • reports
  • campaigns
  • culture sites
CSS / patterns
CSS grid with named areas, drop caps, figcaption, sticky table of contents.
Avoid
Mistakes to avoidTreating every page as a blog template, over-animating text, poor line length.

04

Swiss Style

Grid discipline, objective clarity, asymmetric balance, typography over decoration. It suits design portfolios, cultural institutions, architecture, technical brands and premium informational sites. Typography does much of the work: strong sans serif; precise scale; weights and alignment provide hierarchy. On color, limited palette; black/white/neutrals with one or two strong accents. The grid is part of the idea, not a container dropped on afterwards: strict modular grid; mathematical spacing; strong alignment; asymmetry within grid. Interaction is precise, linear or crisp easing; underline/rule movement.

Best for
  • design portfolios
  • cultural institutions
  • architecture
  • technical brands
  • premium informational sites
CSS / patterns
CSS grid, baseline rhythm, clamp(), grid overlays during development.
Avoid
Mistakes to avoidRandom asymmetry, decorative clutter, centered generic layouts.

Structure carries the rest: can be unconventional; visible structure; abrupt spacing but intentional.

Best for

Neo Brutalism

Color is part of the definition rather than an afterthought: strong color blocks; saturated but controlled palette; no subtle gradients. Layout decisions stay consistent with that: structured, playful asymmetry; clear modular spacing. The components follow suit: blocky nav; hero with stacked graphic panels; cards with thick borders/offset shadows; buttons pop on press; forms large and outlined; icons bold line/filled.
