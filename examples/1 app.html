01 — The equaliser

Five bands, summed properly, written to the hardware.

Move a slider and the curve is recalculated from the actual filter maths — five peaking sections in series, not a wiggle drawn by hand. Whatever you land on is stored on the unit, so the EQ stays put when the app is closed.

02 — What it actually does

Six jobs, and none of them need an account.

The app talks to the unit over USB and does nothing else. No sign-up, no telemetry, no cloud service to go down in February.

A / Firmware

Updates without a website

Firmware is signed, staged and verified on the device itself. If a download is interrupted the unit keeps the version it already has, and the app tells you what it was rather than showing a progress bar that lies.

  • Signed images, verified on-device before flash
  • Two-year rollback to any previous release
  • Release notes in plain language, opened in the app
  • Offline install from a file on a USB stick

Per-source trims

Your DAC measures a hot streaming master and a quiet one. Set a trim per source once; the app remembers it by input, not by app.

C / Log

The measurement log

Every session is recorded: volume, bias, format, peak level. Export it as CSV and you have a listening log that actually means something.

Retention
Unlimited, on device
Export
CSV · JSON
D / Room

Roon, properly

Roon Native discovers the unit on its own and exposes it as an endpoint with the correct sample rates. No manual IP entry.

03 — Setup

Three steps, about four seconds.

01

Plug it in

USB-C from the unit to the computer. The app finds it over the bus; no pairing, no driver, nothing to install first.

Meridian appears in the sidebar
02

Match the bias

Run the bias match. It plays a sweep, measures the current draw and tells you whether 0, 2 or 4 V suits the headphones you have connected.

About 20 seconds, once
03

Set the curve

Start from a measurement of your room, or from a preset, then move three sliders and listen. The unit stores the result; the app can close.

Saved on device, survives a power cut
